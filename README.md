# 🚀 Space Birthday

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://space-birthday.streamlit.app/)

An interactive web application built with Streamlit that allows you to discover what the universe looked like on your exact birthday. The app connects to the official **NASA APOD (Astronomy Picture of the Day) API** to fetch historical space imagery and astronomical reports.

## 🎯 How to use it:
1. Open the link above.
2. Enter any date from June 16, 1995 to the present day.
3. **Enjoy the photo!**

## 🛠️ Tech Stack
1. Python
2. Streamlit
3. NASA APOD API
